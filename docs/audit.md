## Ограничения кейса

Сохраняет FastAPI, LangGraph, FastMCP и PostgreSQL. Интерфейс
перенесён с React на Streamlit. Пользователь проходит один сценарий от ввода
события до утверждения отчёта; LLM получает результаты для рекомендаций через MCP.

- Синтетические данные и экспертные допущения, без банковской калибровки.
- Шоки одинаковы для всех компаний; временная структура постоянна.
- Независимые треугольные распределения и одна выборка Соболя; нет оценки ошибки квантилей.
- Приложение проверяет ссылки рекомендаций и отклоняет текст с цифрами;
  обоснованность рекомендаций проверяет человек.
- Имя подтверждающего вводится вручную; аутентификации нет.
- Один API worker; нет очереди и многопользовательской изоляции.
- После сбоя на границе записи данных/чекпоинта возможен повтор LLM-вызова.
- Локальная LLM должна поддерживать tool calls; иначе этап завершается ошибкой.
- При ошибке LLM запуск не переключается на `mock`.

## Проверки

Автотесты покрывают ручной численный пример, общую матрицу и портфельные квантили,
границы/пропуски входных данных, ссылки и числа в рекомендациях, MCP-изоляцию,
диалог HTTP tool-call, восстановление чекпоинтов и полный путь Streamlit.

Ручная сквозная репетиция выполняется с PostgreSQL командой `msa.ps1 rehearse`.
Подключение DeepSeek отдельно проверялось на тестовых данных без чтения данных
проекта: получение результатов через MCP, рекомендации и генерация сценария.
