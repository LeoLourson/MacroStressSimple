# MacroStress — кейс

<!-- impeccable:product-schema 1 -->

## Platform

web

## Назначение

Провести пользователя через стресс-тест: событие → сценарий LLM → подтверждение человеком →
численный стресс-тест → рекомендации LLM через MCP → утверждение отчёта.

## Объём

Один синтетический портфель корпоративных кредитов. Интерфейс — одна страница
Streamlit с последовательными этапами и историей запусков; бэкенд — FastAPI,
LangGraph, FastMCP и PostgreSQL.
Локальный стенд; модель prod-2 не воспроизводит полный Track A v3.2.

## Ограничения

Финансовая логика находится в `src/msa/assets/`. Названия типов, полей, драйверов
и метрик приходят из API. P5/P50/P95 показываются вместе; у значений указан источник.
Пользователь подтверждает численные допущения до расчёта и утверждает отчёт перед
скачиванием. Для рекомендаций LLM запрашивает результаты текущего запуска через MCP.
Визуальные правила описаны в [.impeccable.md](.impeccable.md).
